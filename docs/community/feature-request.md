# Feature request template

## Problem

What evidence or workflow is impossible today? Reference the capability order
(Measure → Analyze → Diagnose → Compare → Explain → Recommend → Optimize).

## Proposal

Concrete behavior: commands, outputs, schemas touched, and what stays
unchanged (thresholds, detectors, and schema versions need Tier justification
per the contributing rules).

## Non-goals

What this request explicitly does not change (hardware claims, network
behavior, version bumps).

## Acceptance

How would a reviewer verify this without special hardware? Name the tests,
goldens, or docs that prove it.
