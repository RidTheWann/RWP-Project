# Code of Conduct

## Expected behavior

- Technical discussion stays on facts, evidence, and reproducible results.
- Review assumes good intent and corrects respectfully when disagreeing.
- Security and privacy reports follow `SECURITY.md` (private channel, never
  public issues for suspected vulnerabilities).

## Unacceptable behavior

- Harassment, discrimination, or personal attacks in any project space.
- Publishing private data (paths, process inventories, credentials, unredacted
  bundles) belonging to others.
- Deliberately weakening tests, lint gates, or verification to land a change.

## Enforcement

Report violations privately to the maintainer (channel published with the new
repository; see `SECURITY.md`). The maintainer may warn, restrict
participation, or remove content. Retaliation against reporters is itself a
violation.
