## Elevated runbook (paste into an Administrator PowerShell at repo root)

```powershell
# 0. Confirm elevation + preflight (expect permissions_ok true here).
.\target\debug\rwp.exe doctor --presentmon C:\Tools\PresentMon.exe

# 1. Two 60 s captures of the same scenario (PIDs differ per boot; name is stable).
.\target\debug\rwp.exe capture --presentmon C:\Tools\PresentMon.exe --process-name dwm.exe --duration-seconds 60 --output-dir smoke-out\live-dwm-run1
.\target\debug\rwp.exe capture --presentmon C:\Tools\PresentMon.exe --process-name dwm.exe --duration-seconds 60 --output-dir smoke-out\live-dwm-run2

# 2. Offline pipeline per run (import not needed: capture persists the session).
.\target\debug\rwp.exe analyze --session smoke-out\live-dwm-run1 --output-dir smoke-out\live-dwm-run1-analyzed
.\target\debug\rwp.exe report --session smoke-out\live-dwm-run1-analyzed --format md --output smoke-out\live-dwm-run1-summary.md
.\target\debug\rwp.exe analyze --session smoke-out\live-dwm-run2 --output-dir smoke-out\live-dwm-run2-analyzed
.\target\debug\rwp.exe report --session smoke-out\live-dwm-run2-analyzed --format md --output smoke-out\live-dwm-run2-summary.md

# 3. Same-scenario comparison of the two runs.
.\target\debug\rwp.exe compare --baseline smoke-out\live-dwm-run1-analyzed --candidate smoke-out\live-dwm-run2-analyzed --same-scenario

# 4. (Alternative) full smoke-kit pass over a produced CSV (QPC from above).
powershell -ExecutionPolicy Bypass -File tools/smoke-test.ps1 -PresentMon C:\Tools\PresentMon.exe -CsvPath smoke-out\live-dwm-run1\presentmon.csv -ProcessId <dwm-pid-run1> -QpcFrequencyHz 10000000 -OutDir smoke-out
```

Opening the elevated shell: right-click PowerShell → Run as administrator, or
`Start-Process powershell -Verb RunAs` (UAC consent is interactive and cannot be
automated from here). Joining the `Performance Log Users` group is the persistent
alternative (needs one elevated `net localgroup` call, then re-logon).
